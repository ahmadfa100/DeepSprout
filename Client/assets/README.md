# Runtime assets

This is the single location for media used by the website.

- Page folders (`auth`, `community`, `garden`, `home`, `home-redesign`, `insights`, `onboarding`, `pricing`, `recovery`, `shield`, `training`) hold their illustrations and images.
- `brand/` holds the main logo and shared floral marks.
- `home-kit/` holds shared navigation icons and the retained admin illustration.
- `hero/`, `hero-v2/`, and `journey/` hold animation assets and editable export sources.
- `reels/` holds narrative data, `videos/`, and consistently numbered `posters/`.
- `vendor/` holds unmodified third-party runtimes and their licenses.

Authoring source copies under `hero/bimo-source/` and `hero-v2/bimo-source/` are separate export projects. Matching controller and pose files, tool configuration, and license files are retained because each project needs them locally.

See [design references](../references/README.md) for source reference artwork and [illustration prompt notes](../docs/design/image-prompts/README.md) for image-generation history.
