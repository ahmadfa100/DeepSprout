Installation guide · Chrome 120+
  1. Open the repository folder Client/extensions/digital-shield.
  2. In Chrome, open chrome://extensions, enable Developer mode and choose Load unpacked. Select that folder containing manifest.json. Extract any ZIP first.
  3. Use this site at http://127.0.0.1:8897 or http://localhost:8897. Other origins and incognito are unsupported.
  4. Open the extension popup, create a pairing code and paste it below. Pair only with your own active Individual account.

After an extension update or reload, reload this page. If permissions were removed, restore site access in Chrome’s extension details, then use Refresh status. Removing the extension, other browsers and other devices bypass protection.

Privacy, measurement limits and local history

Only selected-domain identifiers, aggregate eligible seconds, local period/timezone, coverage, configuration and session events are stored. Full URLs, search terms and unrelated browsing history are not retained or shared with partner workspaces. Records are browser-local and editable by the device owner; they are not server-verified.

Only consecutive observations of an active selected tab, a focused non-minimized window and Chrome’s active idle state count. Suspension, shutdown, unsupported pages and uncertain intervals are excluded. Missing data is unknown, never proof of zero use. A single reminder acknowledgement applies per local day and timezone, even after a threshold change.
