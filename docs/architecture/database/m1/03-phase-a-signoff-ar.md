# اعتماد قاعدة البيانات M1 — 1 نوفمبر 2026

**النتيجة: PASS لتطوير قاعدة البيانات في M1.** اختبرت قاعدة `DeepSprout_Validation` وحدها على `DESKTOP-A4AL2KR` (SQL Server 2025 RTM، الإصدار `17.0.1000.7`). لم أُشغّل أوامر على `CourseHubDB` أو أي قاعدة أخرى.

## ما نُفّذ

- أُضيف ترحيل EF Core الرابع `20261101053400_CancellationAndWithdrawalRights` دون تعديل الترحيلات الثلاثة المطبقة سابقاً. بقيت بيانات الاختبار القديمة موجودة.
- أصبح إلغاء المبادرة أمراً ذرياً ودائماً، مسموحاً لممثل المؤسسة النشط أو صاحب منحة المنصة `InitiativeCancellationAdmin`. يسجل السبب والفاعل والوقت؛ يغلق الطلبات المفتوحة بحالة `Cancelled` وسبب `InitiativeCancelled` وقرار مستقل، وينهي العضويات `Accepted`/`Suspended` بحالة `Cancelled` وسبب `InitiativeCancelled` ويحرر مقاعدها. بقيت الطلبات المقبولة، القرارات، المراجعات المنشورة، والعضويات المكتملة محفوظة.
- أضيفت قيود `CHECK` ومرجع `CancelledByPersonId`، وأمر تطبيق `CancelInitiativeAsync`. لا تقبل الأوامر طلباً أو اعتماداً أو إعادة جدولة أو نشر مسودة بعد الإلغاء. يرفض التكرار دون آثار إضافية.
- يستخدم الأمر العام وقت SQL الفعلي. إجراء الساعة المحكومة `ops.EndMembershipAt` مخصص للاختبار؛ دور التشغيل محروم من استدعائه مباشرة (`SQL 229`) ويستطيع استدعاء الأمر العام.
- عند تأجيل البداية يمتد حد انسحاب العضويات النشطة؛ وعند تقديمها لا يقصر حقاً مُنح سابقاً. تبقى مراجعات النشر التاريخية ثابتة. يُرفض موعد بدء مضى (`SQL 51601`).
