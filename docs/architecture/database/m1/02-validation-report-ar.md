## التصحيح والتنفيذ

أُنشئ [عقد M1 المصحح](01-corrected-dictionary.md) قبل الترحيل، منفصلًا عن v2.1. أضيفت تصريحات الأعمدة الاثني عشر المفقودة في 11 جدولًا، وأعمدة أحداث إضافية تحتاجها الأوامر. فحص القاموس القابل للإعادة أعاد `19` جدولًا و`12/12 PASS`، مقابل `12 FAIL` في الفحص الساكن للحزمة الأصلية.

تُطبق قرارات المنتج الأحدث: محاولة جديدة بعد `Rejected` العادي مع أهلية قائمة، منع `Blocked`، عضوية Initiative فعالة واحدة للشخص، سعة 1..135 عددية، تحرير السعة عند `Withdrawn/Removed/Completed`، احتساب `Suspended`، وقطع الانسحاب الطوعي عند **120 ساعة UTC قبل البداية** بشرط `now < cutoff`. يعيد أمر الجدولة إصدار Revision جديدًا ويحفظ موعد القطع المثبت في العضويات القديمة. إعادة الانضمام بعد عضوية سابقة في المبادرة نفسها ما زالت ممنوعة لحين قرار مالك مستقل.

الهيكل: `Domain` مستقل، و`Application` لعقود الأوامر وDTOs، و`Infrastructure` لـ`DeepSproutDbContext` واحد وEF Core SQL Server وعمليات SQL الذرية، ثم مشروع اختبارات تكامل. لا توجد مسارات ASP.NET Core أو API كامل. استُخدم EF Core `10.0.0` و.NET `10`، مع تحديث مباشر لحزم التشفير التابعة إلى `10.0.14`؛ آخر بناء للـsolution أعاد **0 تحذيرات، 0 أخطاء**.

## أخطاء مرصودة خلال التنفيذ

أول محاولة لـ`InitialM1` فشلت بخطأ SQL Server **113** (`Missing end comment mark '*/'`) لأن فاصل دفعات ظهر داخل تعليق مورد SQL. فحص ما بعد الفشل وجد فقط `dbo.__EFMigrationsHistory` بلا أي سجل ترحيل أو جدول M1؛ صُحح التعليق وأُعيد تطبيق الترحيل بنجاح. في تطوير برنامج الاختبار ظهر `InvalidCastException` عند قراءة `@@SPID` كـ`Int32` بدل `Int16`، ثم SQL **334** عند استعمال `OUTPUT` مباشرًا على جدول له Trigger؛ صُحح التجهيزان وأُعيدت المجموعة كاملة إلى 0 FAIL. هذه إخفاقات محاولات سابقة، وليست نتائج PASS مُدعاة لتلك المحاولات. [سجل المحاولات](evidence/attempts.md) يحفظ التسلسل.

## حدود التوقيع

اختبارات أوامر التفويض تعتمد `ActorPersonId` ممررًا من العميل؛ لا يوجد بعد ربط بهوية HTTP موثقة أو صلاحيات تنزيل ملف حقيقية. دور `deepsprout_runtime` وقيود قاعدة البيانات لا يشكلان وحدهما أمن مستخدم نهائي. لذلك النتيجة **GO لاستخدام مخطط M1 داخل قاعدة التحقق فقط، NO-GO للإنتاج أو لاعتماد مصفوفة M1 كاملة**. لا تشمل هذه الشريحة الجداول الـ110 المتبقية، أو واجهة ASP.NET Core، أو قوائم الانتظار، أو سياسات القاصرين وLab/Shield/Provider/Rewards.

تبقى تجهيزات الاختبار في `DeepSprout_Validation` عمدًا لدراسة الدليل؛ لم تُحذف أو تُسقط قاعدة البيانات. أي تنظيف شامل أو حذف قاعدة يحتاج موافقة منفصلة.
